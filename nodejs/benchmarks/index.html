GPU Backend

Section titled “GPU Backend”

For large batch datasets the GPU backend outperforms CPU-parallel execution. The crossover depends on fraction × n:

ScenarioCPU-ParallelGPUSpeedup
n = 1M, fraction = 0.51.24 s187 ms6.6×

At fraction = 0.5, GPU overtakes CPU around n ≥ 50K; at smaller fractions, around n ≥ 100K–250K. See the GPU Backend guide for setup.
