= Changelog

This changelog includes end-user changes only. For internal development notes, see the link:https://github.com/thisisamirv/lowess-project/blob/main/CHANGELOG.md[repository changelog].

== [Unreleased]

=== Added

* Added grouped `outputs(...)`, `cv(CVOptions...)`, and prediction-output APIs while preserving native option mapping.
* Added an "Alternative Software" guide comparing `fastlowess` with Apache Commons Math's `LoessInterpolator`.

== 4.1.0

=== Added

* Added bundled native libraries for the Java binding across 8 platforms, with runtime musl detection and auto-extraction.
* Added `retainModel` and `Result.predictModel()` for prediction.
* Added `returnDerivative(boolean)` to `Options` and `OnlineOptions`.
* Added standard errors and confidence/prediction intervals to `StreamingOptions` and `OnlineOptions`; online intervals require `updateMode("full")`.

=== Fixed

* Changed the `OnlineLowess` default `iterations` from `3` to `0`, matching non-robust incremental updates; robustness iterations require `updateMode("full")`.
* Fixed `Lowess()` accepting negative `cv_seed` values by rejecting negative seeds before casting.

== 4.0.0

=== Added

* Added `returnSorted` to `Options`.
* Added a `missing` option to `Options.Builder`, shared by `Options`, `StreamingOptions`, and `OnlineOptions`, to control non-finite input handling.
* Added `FastLowess.installGpu()` to download a prebuilt GPU library; the Java runtime can load it from a directory set with `-Dfastlowess.native.dir`.
* GPU installers now accept a path to a local GPU artifact, and prebuilt GPU artifacts are available for Linux and Windows ARM64.

=== Changed

* Breaking change: removed `returnDiagnostics`, `returnResiduals`, and `parallel` from `OnlineOptions.Builder`; these options were accepted but had no effect in online mode.
* Breaking change: removed `confidenceIntervals` and `predictionIntervals` from `OnlineOptions.Builder` and `StreamingOptions.Builder`.
* Breaking change: `StreamingOptions.Builder.overlap()` now defaults dynamically to `chunk_size / 10`, clamped to `[1, chunk_size - 10]`, instead of a fixed `500`.
* Improved the Java API documentation, including the overlap default.

== 3.2.1

=== Changed

* Clarified that results are returned in input order, even though the algorithm sorts internally.
* Updated the documentation site's MathJax version for improved mathematical rendering.

=== Fixed

* Fixed `OnlineOptions.Builder` defaulting to parallel execution; it now defaults to serial execution like the other bindings.

== 3.2.0

* Initial release of the Java binding.
