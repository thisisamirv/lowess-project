{{- /* Rewrites relative image paths (e.g. "../assets/diagrams/x.svg") to be depth-independent: strips any number of leading "../" segments (however many the source page's nesting requires) and re-resolves what remains ("assets/diagrams/x.svg") against the site's actual base path via relURL. This means moving a page into (or out of) a category subfolder never breaks its image references. */ -}} {{- $dest := .Destination -}} {{- if not (findRE "^https?://" $dest) -}} {{- $dest = replaceRE `^(\.\./)+` "" $dest -}} {{- $dest = $dest | relURL -}} {{- end -}}
