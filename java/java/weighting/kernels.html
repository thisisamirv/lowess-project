Weight Functions

Kernel functions for distance weighting.

Overview

Weight functions (kernels) determine how neighboring points contribute to each local fit. Points closer to the target receive higher weights.

Efficiency = AMISE relative to Epanechnikov (1.0 = optimal)

All examples below use the same 100-point noisy sine wave (x[i] = i * 2 * Math.PI / (n - 1); y[i] = Math.sin(x[i]) + 0.1, n = 100).

Tricube (Default)

Cleveland’s original choice. Best all-around performance.

\[w(u) = (1 - |u|^3)^3\]

Use when: Default choice for most applications.

import fastlowess.Lowess;
import fastlowess.Options;
import fastlowess.Result;

public class Example {
    public static void main(String[] args) {
        int n = 100;
        double[] x = new double[n];
        double[] y = new double[n];
        for (int i = 0; i < n; i++) {
            x[i] = i * 2 * Math.PI / (n - 1);
            y[i] = Math.sin(x[i]) + 0.1;
        }

        Options options = Options.builder().weightFunction("tricube").build();

        try (Lowess model = new Lowess(options)) {
            Result result = model.fit(x, y);
            System.out.println("First smoothed value (tricube kernel): " + result.y()[0]);
        }
    }
}
First smoothed value (tricube kernel): 0.38260776436644134

Epanechnikov

Theoretically optimal for kernel density estimation.

\[w(u) = \frac{3}{4}(1 - u^2)\]

Use when: Optimal MSE properties desired.

import fastlowess.Options;
import fastlowess.Result;

    public static void main(String[] args) {
        int n = 100;
        double[] x = new double[n];

        for (int i = 0; i < n; i++) {
            x[i] = i * 2 * Math.PI / (n - 1);
            y[i] = Math.sin(x[i]) + 0.1;
        }

        Options options = Options.builder().weightFunction("epanechnikov").build();

        try (Lowess model = new Lowess(options)) {
            Result result = model.fit(x, y);
            System.out.println("First smoothed value (epanechnikov kernel): " + result.y()[0]);
        }
    }
}
First smoothed value (epanechnikov kernel): 0.40672777844316566

Gaussian

\[w(u) = \exp(-u^2/2)\]

Use when: Maximum smoothness needed, computational cost acceptable.

Biweight

Good balance of efficiency and smoothness.

\[w(u) = (1 - u^2)^2\]

Use when: Alternative to Tricube with slightly different properties.

Uniform

Equal weight within the window; no distance decay.

\[w(u) = 1\]

Use when: You want a simple moving-average-like behavior within the neighborhood.

import fastlowess.Options;

            x[i] = i * 2 * Math.PI / (n - 1);

        try (Lowess model = new Lowess(options)) {
            Result result = model.fit(x, y);

\[w(u) = 1 - |u|\]

Use when: A simple, cheap-to-evaluate kernel with compact support is preferred.

Cosine

Smooth compact-support kernel, close in efficiency to Tricube.

\[w(u) = \cos\!\left(\frac{\pi u}{2}\right)\]

Use when: An alternative smooth kernel to Tricube is desired.
